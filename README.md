# CalFood 🥗

แอปพลิเคชันสำหรับคำนวณและติดตามการรับประทานแคลอรี่รายวัน พัฒนาด้วย Android Jetpack Compose

## คุณสมบัติเด่น (Features)
- **จัดการข้อมูลส่วนตัว:** ตั้งค่า ชื่อ, น้ำหนัก, ส่วนสูง และอายุ เพื่อการคำนวณที่แม่นยำ
- **คำนวณ BMR & TDEE:** ใช้สูตร Mifflin-St Jeor สากลเพื่อหาความต้องการพลังงานต่อวันของแต่ละบุคคล
- **บันทึกการรับประทาน:** เลือกรายการอาหารไทยยอดนิยมพร้อมระบุแคลอรี่
- **สรุปผลรายวัน:** แสดงกราฟสถิติการกินย้อนหลัง เพื่อเปรียบเทียบกับเป้าหมาย
- **UI/UX ทันสมัย:** มาพร้อมอนิเมชันที่ลื่นไหลและการตอบสนองที่รวดเร็ว (Bounce Click, Chart Growth)

## เทคโนโลยีที่ใช้ (Tech Stack)
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Modern UI)
- **Architecture:** MVVM (ViewModel, State Management)
- **Local Storage:** SharedPreferences
- **Graphics:** Compose Canvas (Custom Charting)

## การติดตั้ง (Installation)
1. Clone repository นี้ไปยังเครื่องของคุณ
2. เปิดด้วย Android Studio (เวอร์ชันล่าสุด)
3. Build และ Run บน Android Device หรือ Emulator
